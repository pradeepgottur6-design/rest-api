# 🚀 REST API with Node.js + Data Visualization

A simple REST API built using **Node.js and Express** to manage notes, along with a **data visualization dashboard** using Chart.js.

---

## 📌 Project Overview

This project demonstrates the implementation of a RESTful API with full CRUD operations and a visual representation of API data.

Developed as part of a **Full Stack Development Internship Task**, this project showcases both backend functionality and frontend visualization.

---

## ✨ Features

### 🔹 REST API (Backend)
- Create notes (POST)
- View all notes (GET)
- View a single note (GET by ID)
- Update notes (PUT)
- Delete notes (DELETE)

### 🔹 Data Visualization (Frontend)
- Bar chart representation of notes
- Displays note IDs and corresponding text
- Interactive tooltips
- Responsive UI design

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js  
- **Frontend:** HTML, CSS  
- **Visualization:** Chart.js  
- **Testing Tool:** Postman

## 🔗 API Endpoints

| Method | Endpoint        | Description        |
|--------|----------------|--------------------|
| GET    | /notes         | Get all notes      |
| GET    | /notes/:id     | Get a single note  |
| POST   | /notes         | Create a new note  |
| PUT    | /notes/:id     | Update a note      |
| DELETE | /notes/:id     | Delete a note      |
